REMYELLIS.AU — PORTFOLIO SITE
============================

This is a static HTML/CSS/JS website based on the Hyperspace template by HTML5 UP,
customised into a light academic portfolio with a blue/teal visual system.

Main files:
- index.html                 All page content
- assets/css/remy.css        Custom colours and layout styling
- assets/css/main.css        Original Hyperspace base styles
- assets/js/                 Original template JavaScript

To add a paper:
Copy one <article class="publication">...</article> block in the Research section
of index.html and replace its title, metadata, description and link.

To add a software project:
Copy one <article class="project-card">...</article> block in the Software section.

To add a story:
Copy an <article>...</article> block from the Writing section.

Everything is ordinary static HTML, CSS and JavaScript. No build step or framework is required.

Base template licence and credit are retained in LICENSE.txt and the footer.
